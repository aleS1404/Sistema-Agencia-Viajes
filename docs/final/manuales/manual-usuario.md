# Manual de usuario

**Estado:** recorridos funcionales validados; capturas visuales pendientes.

## Cliente

1. Registrarse e iniciar sesión.
2. Completar perfil, presupuesto, días e intereses.
3. Buscar, filtrar y comparar servicios.
4. Consultar recomendaciones.
5. Crear reserva y revisar itinerario.
6. Registrar un pago simulado.
7. Consultar estado, cancelar, solicitar reembolso o registrar reclamo.

## Administrador

1. Gestionar usuarios y estados.
2. Mantener proveedores, destinos, categorías y servicios.
3. Validar información propuesta por proveedores.
4. Configurar políticas comerciales.
5. Consultar reportes y auditoría.

## Proveedor

1. Iniciar sesión con cuenta vinculada.
2. Consultar y actualizar sus servicios.
3. Enviar cambios para validación administrativa.

## Soporte

1. Revisar cancelaciones y reembolsos.
2. Aprobar o rechazar conforme a política.
3. Asignar y resolver reclamos.
