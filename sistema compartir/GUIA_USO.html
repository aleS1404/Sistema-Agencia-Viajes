AndesGo · manual resumido

Guía de uso

Abra http://localhost:5173 después de ejecutar 3_INICIAR_SISTEMA.bat. Todas las cuentas usan la contraseña Demo1234!.

Ingreso al sistema

  1. Escriba el correo correspondiente al rol.
  2. Ingrese la contraseña demostrativa.
  3. Presione Ingresar. El menú se adapta automáticamente a los permisos del usuario.
ADMINISTRADOR

Administración

Correo: admin@andesgo.demo

  1. Revise usuarios y cambie estados o roles.
  2. Administre catálogo y políticas.
  3. Abra Dashboard para KPI, filtros, predicción y riesgo de cancelación.
  4. Abra Asistente IA y use preguntas sugeridas sobre reservas, ingresos o reclamos.
CLIENTE

Viajes y recomendaciones

Correo: cliente@andesgo.demo

  1. Explore el catálogo con fotografías y filtros.
  2. Abra Para ti para recomendaciones explicables.
  3. Cree una reserva y registre un pago simulado.
  4. Consulte itinerario, cancelación, reembolso o reclamo.
SOPORTE

Atención al cliente

Correo: soporte@andesgo.demo

  1. Abra la bandeja de atención.
  2. Revise cancelaciones y solicitudes de reembolso.
  3. Apruebe o rechace casos demostrativos.
  4. Documente la resolución de reclamos.
PROVEEDOR

Servicios turísticos

Correo: proveedor@andesgo.demo

  1. Abra Mis servicios.
  2. Revise los servicios asociados a la cuenta.
  3. Cree una propuesta de servicio.
  4. Actualice información para revisión administrativa.

Interpretación del dashboard

ElementoSignificado
KPIReservas, confirmaciones, ingresos simulados, cancelaciones, reclamos, servicios y usuarios.
PredicciónRegresión lineal académica basada en datos sintéticos. No es una proyección comercial real.
RiesgoPuntaje preventivo con factores visibles. No cancela ni rechaza automáticamente.
AsistenteRespuestas por intenciones y consultas predefinidas; no utiliza un servicio generativo externo.
Alcance: no utilice información personal real. Los pagos, reservas, clientes, estadísticas y predicciones son exclusivamente demostrativos.

Cerrar correctamente

Cierre la sesión desde el menú y ejecute 4_DETENER_SISTEMA.bat. Esto detiene la API y la web; los datos permanecen guardados en MySQL.
