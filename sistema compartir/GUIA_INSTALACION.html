AndesGo · instalación local sin Docker

Guía de instalación

Esta distribución instala el prototipo en Windows usando Node.js y MySQL. No requiere Docker ni conocimientos de programación.

1. Requisitos

ProgramaVersiónDescarga
Windows10 u 11 de 64 bitsYa incluido en el equipo
Node.js22 o superiornodejs.org
MySQL Server8.0 u 8.4MySQL Installer
Durante la instalación de MySQL: seleccione Server Only o Developer Default, conserve el puerto 3306 y recuerde la contraseña asignada al usuario root.

2. Instalación guiada

1

Descomprimir

Extraiga todo el ZIP. No ejecute archivos directamente desde la ventana del ZIP.

2

Instalar dependencias

Ejecute 1_INSTALAR_DEPENDENCIAS.bat. Descargará las librerías y compilará la API y la web. Requiere internet y puede tardar varios minutos.

3

Configurar MySQL

Confirme que el servicio MySQL esté iniciado. Ejecute 2_CONFIGURAR_MYSQL.bat, escriba RECREAR y proporcione la contraseña de root. Se crearán 19 tablas, 16 usuarios y datos sintéticos.

Advertencia: el paso 3 elimina y recrea exclusivamente la base booking_demo. No afecta otras bases de datos, pero elimina datos previos de AndesGo.
4

Iniciar

Ejecute 3_INICIAR_SISTEMA.bat. La API y la web se ejecutarán en segundo plano y se abrirá http://localhost:5173.

5

Detener

Al terminar, ejecute 4_DETENER_SISTEMA.bat. MySQL puede permanecer iniciado para la siguiente sesión.

4. Solución de problemas

“No se encontró Node.js”

Instale Node.js, cierre las ventanas de comandos y vuelva a ejecutar el paso 1.

“No se encontró mysql.exe”

Instale MySQL Server. El script reconoce instalaciones estándar de MySQL 8.0, 8.4 y XAMPP.

MySQL rechaza la contraseña

Utilice la contraseña de root creada durante MySQL Installer. No es Demo1234!.

Los puertos están ocupados

Cierre otros servidores que usen 3000 o 5173. Los detalles se guardan en AndesGo\logs.

La pantalla no abre

Espere diez segundos y visite manualmente http://localhost:5173. Compruebe que MySQL esté en ejecución.
